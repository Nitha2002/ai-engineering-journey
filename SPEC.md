# Task Manager API

## Goal

Build a simple task management API for learning modern software engineering and AI-assisted development.

## Core Features

- Create a task
- View all tasks
- View a single task
- Update a task
- Delete a task
- Mark a task as completed

## Task Fields

Each task should contain:

- ID
- Title
- Description
- Status
- Created date
- Updated date

### Status Values

A task can have one of these statuses:

- `pending`
- `in_progress`
- `completed`

## Initial Requirements

The API should:
- Validate user input
- Return appropriate HTTP status codes
- Handle errors clearly
- Use a database for persistent storage
- Include automated tests

## Learning Goal

The project should be developed using AI-assisted software engineering practices.

I should understand the architecture, review generated code, test the implementation, debug errors, and be able to explain the final project.
